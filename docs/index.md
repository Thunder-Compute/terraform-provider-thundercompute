# Thunder Compute Provider

The Thunder Compute provider manages GPU instances, SSH keys, and snapshots on the [Thunder Compute](https://thundercompute.com) platform.

Use the Registry source `Thunder-Compute/thundercompute`. Existing users should read the [v0.1.0 to v0.2.0 migration guide](guides/version-0.2-migration.md) before upgrading state.

## Authentication

Set the `TNR_API_TOKEN` environment variable or configure the `api_token` attribute directly:

```shell
export TNR_API_TOKEN="your-api-token"
```

Generate tokens at [console.thundercompute.com/settings/tokens](https://console.thundercompute.com/settings/tokens).

Sensitive attributes are redacted from normal CLI output but remain in Terraform state. Use encrypted remote state with restricted access and prefer user-supplied SSH public keys.

## Example Usage

```terraform
terraform {
  required_providers {
    thundercompute = {
      source  = "Thunder-Compute/thundercompute"
      version = "~> 0.2.0"
    }
  }
}

provider "thundercompute" {
  # api_token is read from the TNR_API_TOKEN environment variable by default.
  # Uncomment the line below to set it explicitly:
  # api_token = var.thunder_api_token
```
